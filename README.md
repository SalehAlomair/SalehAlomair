## Selected Work

### EvidenceOps Agent
Retrieval-augmented agent built on LlamaIndex and AWS Bedrock. Handles document ingestion, structured retrieval, and grounded response generation over evidence corpora.
`LlamaIndex` `AWS Bedrock` `Python`

### Riyadh Metro RAG Assistant
Arabic-aware retrieval-augmented assistant answering transit questions from official documentation. Built to handle dialectal and Modern Standard Arabic queries.
`RAG` `Vector Search` `Arabic NLP`

### Aircraft Surface Damage Detection
Graduation project. Two-stage pipeline combining VGG16 classification with Salesforce BLIP captioning to detect and describe surface defects on aircraft.
`TensorFlow` `Transfer Learning` `BLIP`

### Land Surface Temperature Classification
CNN classifier over Sentinel-2 and MODIS satellite imagery, categorizing tiles as Cold / Moderate / Hot. Compared four architectures across a 2,815-image dataset; best model reached 75.2% test accuracy and 74.5% macro-F1.
`CNN` `Geospatial` `PostgreSQL`

### Prompt Classification Benchmark
Comparative evaluation of TF-IDF baselines against Claude Haiku via AWS Bedrock across zero-shot, few-shot, and chain-of-thought prompting strategies.
`LLM Evaluation` `AWS Bedrock` `scikit-learn`
